# F-01 회원가입

```mermaid
sequenceDiagram
    actor 사용자
    participant AuthController
    participant AuthService
    participant UserRepository
    participant Database

    사용자->>AuthController: 회원가입 요청
    AuthController->>AuthService: 회원가입 처리 요청
    AuthService->>UserRepository: 아이디/닉네임 중복 확인
    UserRepository->>Database: 중복 여부 조회
    Database-->>UserRepository: 조회 결과
    UserRepository-->>AuthService: 중복 여부 반환
    AuthService->>UserRepository: 비밀번호 암호화 후 회원 저장
    UserRepository->>Database: 회원 정보 저장
    Database-->>UserRepository: 저장 결과
    UserRepository-->>AuthService: 생성된 회원 정보 반환
    AuthService-->>AuthController: 회원 정보 반환
    AuthController-->>사용자: 가입 완료 응답
```

# F-33, F-34 GitHub 로그인/Google 로그인

```mermaid

    participant Database

    AuthService->>Database: 회원 생성 및 토큰 발급
    Database-->>AuthService: 저장 결과
    AuthService-->>사용자: 가입 완료 및 로그인 응답
```
